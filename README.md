# Login UI

Interfaz de inicio de sesión moderna y adaptable, desarrollada con HTML5 y CSS3. Este proyecto explora la composición visual de formularios, la jerarquía de información y la creación de una experiencia de acceso clara en distintos tamaños de pantalla.

## Características

- Diseño responsive para diferentes tamaños de pantalla.
- Fondo visual con imagen y efecto de desenfoque.
- Formulario de usuario y contraseña.
- Opción para recordar la sesión en la interfaz.
- Enlaces de recuperación de contraseña y registro.
- Iconografía con Boxicons y tipografía Poppins.

## Tecnologías

- HTML5
- CSS3
- Boxicons
- Google Fonts

## Ejecutar localmente

No necesita instalación de dependencias.

```bash
git clone https://github.com/miguelagcz/Login.git
cd Login
```

Abre `index.html` en tu navegador o utiliza la extensión Live Server de Visual Studio Code.

## Qué demuestra

Práctica de maquetación semántica, estilos reutilizables, composición de formularios y adaptación responsive. La interfaz es una demostración visual; no implica autenticación real ni conexión a un backend.
