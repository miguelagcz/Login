# Login UI

Interfaz de inicio de sesión moderna y responsive, desarrollada con **HTML y CSS**. El proyecto busca crear una pantalla de login limpia, visual y adaptable a diferentes tamaños de pantalla.

## ✨ Características

- Diseño responsive.
- Fondo con imagen y efecto de desenfoque.
- Formulario de usuario y contraseña.
- Opción **Remember me**.
- Enlace de recuperación de contraseña.
- Enlace de registro.
- Iconos mediante Boxicons.
- Tipografía Poppins.

## 🛠️ Tecnologías

- HTML5
- CSS3
- Boxicons
- Google Fonts

## 🚀 Cómo ejecutarlo

No requiere instalación ni dependencias.

1. Clona el repositorio:

```bash
git clone https://github.com/miguelagcz/Login.git
```

2. Abre `index.html` en tu navegador.
